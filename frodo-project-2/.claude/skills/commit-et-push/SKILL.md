ALWAYS use this skill when the user asks to commit and push the changes to the remote repository.

Use cli commands to commit and push the changes to the remote repository.

You can use the following commands:
## Add to staging 
- git add .

## Commit the changes
- git commit -m "message"

## Push the changes to the remote repository
When push, NEVER verify project or file, just push the changes.

Use the following command to push the changes to the remote repository: 
- git push
